# SLATEC source notice

This directory contains the 37 SLATEC routines required by the companion's source build. Original routine headers name their authors and references. The source is reused, not authored as part of this thesis.

The [Netlib Guide to the SLATEC Common Mathematical Library](https://netlib.org/slatec/guide), July 1993, Section 4, states: “The Library is in the public domain”. This source status was checked against the primary Netlib guide on 5 November 2026. No license is inferred for the unrelated BspQed modules or other project code from that statement.
